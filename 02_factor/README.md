# 02_factor · 因子构造

**这一层要解决的问题：用什么变量去解释/预测收益。**

## 两个世界（我现在正在从左边走向右边）

| | 时间序列因子 | 横截面因子 |
|---|---|---|
| 例子 | KD / MACD / RSI / BOLL | 市值、动量、换手率、ROE、账面市值比 |
| 逻辑 | 这只股票跟**自己的历史**比 | 这只股票跟**同一时点的别的股票**比 |
| 谁在用 | 技术分析、个人交易者 | 学术资产定价、机构 |
| 我的现状 | 已做 36 组回测 | 刚开始 |

**这是我目前最大的能力缺口，也是升级方向。**

## 目标

- [ ] 时变 Beta：20 日 / 60 日滚动 Beta（东吴《金融计量》已教，换 A 股数据重做）
- [ ] 横截面特征库：目标 30–90 个（Gu-Kelly-Xiu 原文用了 94 个）
- [ ] 横截面标准化（每月内 z-score + 截尾）
- [ ] 行业中性化

## 重要提醒

Hull《期权、期货及其他衍生产品》Ch14 原文：
> 股价服从马可夫过程 ⟹ 基于历史价格的交易规则无法持续获得超额收益 ⟹ 技术分析无效。

我手上那 36 组技术指标回测，本质上是在**检验**这个假设，而不是默认它成立。
这个立场要在 README 里写清楚 —— 它决定了别人怎么看我的严谨性。
