# 05_ml_asset_pricing · 机器学习资产定价

**复现 Gu, Kelly & Xiu (2020) *Empirical Asset Pricing via Machine Learning*, Review of Financial Studies**

这是整个作品集的**主线项目** —— 它直接对应厦大姜富伟教授的研究方向
（大数据与人工智能驱动的资产定价）。

## 为什么选这篇

- 它是机器学习资产定价的奠基之作，被引数千次
- 方法清晰可复现：公司特征 → 预测下月收益 → 多空组合
- 有 A 股版本可以对标（姜富伟等《基于自编码机器学习的资产定价研究》，管理科学学报）
- 它能把我已有的 36 组回测经验，升级到学术资产定价的框架

## 怎么跑

```bash
pip install -r ../requirements.txt
python 04_A股机器学习资产定价_复现骨架.py
```

当前为**演示模式**：6 只 ETF（512480 / 510300 / 159915 / 510880 / 512690 / 512010）+ SHIBOR 无风险利率，跑完会打印样本外 R² 与多空十分位统计。

> 演示模式的样本量远不足以支撑结论，它的作用是**验证流程通**。换全 A 股请看下方待办。

## 文件

- `04_A股机器学习资产定价_复现骨架.py` —— 完整流程骨架（已通过语法检查）

## 流程

```
akshare 拉日线
    ↓
日线 → 月线面板
    ↓
构造横截面特征（当前 12 个，目标 90 个）
    ↓
每月内 z-score 标准化 + 截尾
    ↓
滚动窗口训练（60 个月训练 → 预测当月）  ← 绝对不能用随机切分
    ↓
样本外 R² + 横截面 IC
    ↓
多空十分位组合 → 年化 / 夏普 / 最大回撤
    ↓
特征重要性
```
