# 03_backtest · 回测引擎

**这一层要解决的问题：策略在真实约束下到底赚不赚钱。**

## 已有的存量代码（待从桌面 `量化/` 迁移进来）

- `run_backtest.py` / `run_backtest_v2.py`：单策略回测
- `run_batch_backtest.py`：批量回测（6 策略 × 6 板块 = 36 组）
- `run_paper_trading.py` / `run_replay_visual.py`：历史回放模拟盘
- `strategies/`：策略实现

## 已完成的结果

批量回测 36 组的部分结论：
- 半导体 → MACD（夏普 0.88）
- 红利 → RSI（夏普 0.56）
- 创业板 → BOLL（夏普 0.72）

历史回放模拟盘（512480 半导体 ETF，MACD 策略）：
- 年化 3.59% / 夏普 0.90 / 最大回撤 −4.96%
- 47 次买入 + 32 次卖出 + 10 次止盈 + 3 次止损 + 20 次冻结

## 必须包含的三个真实约束

1. **佣金**（万三）
2. **滑点**
3. **T+1**（当天买入不能当天卖出）

缺任何一个，回测结果都是假的。这是我的回测和网上大多数「年化 50%」回测最大的区别。
