# notes/ · 论文精读笔记卡

**目标：一年读满 10 张卡。**

方法来自厦大 WISE 副院长陈海强：
> 「写论文前最重要的是精读十篇左右同领域最著名的论文，可以向导师请教，一遍读不懂就甚至读十次二十次，从这十个点出发，就能展开成面，构筑自己的论文框架和文献体系，这个功夫不能省。」

## 规则

1. 每篇一张卡，命名 `NN_第一作者年份_关键词.md`，例如 `01_Gu2020_MLassetpricing.md`
   —— **不要叫 `paper_01.md`**，半年后你自己都认不出是哪篇
2. 固定五栏：研究问题 / 数据 / 方法 / 结论 / **我最想改的一点**
3. **第五栏最重要** —— 它决定你是「复述者」还是「对话者」
4. 读完一张，把一句话版本（面试用）背下来：
   「这篇用__方法__在__数据__上研究__问题__，发现__结论带数字__。」
