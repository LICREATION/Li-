# 论文精读笔记卡 · 模板

> 用法：每读完一篇论文，复制一份这个模板，重命名为 `笔记_N_作者_关键词.md`，放进 GitHub 仓库的 `notes/` 目录。
> 目标：一年读满 10 张。10 张卡片就是你复试时最硬的底牌。
> 方法来自陈海强（厦大 WISE 副院长）：「写论文前最重要的是精读十篇左右同领域最著名的论文，读不懂就甚至读十次二十遍，这个功夫不能省。」

## 三、方法（重点：写到能给别人讲明白）

1. **核心识别/建模策略**是什么？（一句话）
2. 用了什么模型？（OLS / Lasso / 随机森林 / 神经网络 / 自编码器 / ...）
3. **训练与测试怎么切分？** ← 这一栏必填，是你最该关注的技术细节
   - □ 随机切分（金融数据下通常是错的）
   - □ 时间序列滚动 / 扩展窗口
   - □ 其他：
4. 评价指票是什么？（样本外 R² / 多空组合收益 / 夏普 / 信息比率 / ...）

## 五、⭐ 我最想改的一点（这一栏最重要）

> 这一栏决定你是「复述者」还是「对话者」。
> 哪怕写得很幼稚也没关系，**必须有自己的判断**。

可以切入的角度（任选一个）：

- [ ] **数据层面**：换成 A 股会怎样？A 股有涨跌停、T+1、散户占比高，原文的结论还成立吗？
- [ ] **方法层面**：这里的变量切分 / 特征构造有没有问题？有没有未来函数？
- [ ] **样本区间**：原文样本到 20XX 年，最近这几年（注册制、量化新规、AI 行情）结论变了吗？
- [ ] **遗漏变量**：作者有没有控制掉某个明显该控制的因子？
- [ ] **机制解释**：作者给的经济学解释你信吗？有没有别的解释？
