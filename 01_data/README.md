# 01_data · 数据管道

**这一层要解决的问题：数据从哪来、怎么存、怎么增量更新。**

这是整个量化栈的地基 —— 没有它，后面所有的因子和回测都得每次重新抓数据。

## 目标

- [ ] akshare 抓取 A 股 / ETF 日线
- [ ] 存进 SQLite，支持增量更新（只抓新数据，不重复抓）
- [ ] 数据质量检查：缺失值、停牌、复权、异常值
- [ ] 月频面板生成（日线 → 月线）

## 已有的基础

东吴《金融大数据》课程 CH08 教过：TWSE 爬虫 → 清洗 → SQLite → KD 回测。
要把它从台股移植到 A 股（TWSE 旧 API 大概率已失效，不要在原端点上耗时间）。

## 关键坑（写在前面，避免重复踩）

- 复权必须统一（前复权 vs 后复权混用会导致收益率跳变）
- 停牌日要处理，否则滚动窗口样本量不一致
- **绝不能把未来的数据写进历史** —— 数据入库时就要打上「可知时点」标记
